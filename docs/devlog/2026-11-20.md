# Engine Devlog — November 20, 2026

**Milestone 4 (Phase 1): Asset Loading via `fastgltf` \& GPU Staging Buffers**

## 1\. Overview

Today's session marked a major architectural transition for the Vulkan 3D renderer: moving away from hardcoded cube geometry to dynamically loading and rendering real 3D assets (`DamagedHelmet.glb`) using `fastgltf`. We refactored our vertex and index buffer allocations to use temporary staging buffers for `DEVICE\_LOCAL` VRAM transfers, designed a unified `Model`/`Primitive` slice architecture, and achieved our first successful render of the Damaged Helmet mesh at \~288 FPS.

## 2\. Features Implemented

### GPU Staging Buffer Workflow (`Buffers.h`)

* **Dynamic Buffer Creation:** Refactored `vertexBuffer::createVertexBuffer` and `indexBuffer::createIndexBuffer` to accept dynamic `std::vector<Vertex>` and `std::vector<uint32\_t>` inputs instead of hardcoded arrays.
* **Host-to-Device Transfers:** Implemented a staging buffer workflow (`VK\_BUFFER\_USAGE\_TRANSFER\_SRC\_BIT` with `VMA\_ALLOCATION\_CREATE\_MAPPED\_BIT`) that copies CPU data via `memcpy` and submits a one-time `vkCmdCopyBuffer` command (`eOneTimeSubmit`) to transfer geometry into high-speed `VMA\_MEMORY\_USAGE\_AUTO\_PREFER\_DEVICE` VRAM buffers, immediately freeing the temporary staging allocation afterward.

### Scene \& Mesh Data Structures (`Mesh.h`)

* **Unified Geometry Packing:** Introduced `Primitive` (`firstIndex`, `indexCount`, `vertexOffset`, `transform`) and `Model` (`vertexBuffer`, `indexBuffer`, `std::vector<Primitive>`) structs to pack an entire model's geometry into single contiguous vertex and index buffers while tracking sub-mesh slices.

### `fastgltf` Asset Parser (`Mesh.cpp`)

* **Binary glTF Loading:** Integrated `fastgltf::GltfDataBuffer::FromPath` and `fastgltf::Parser::loadGltf` to parse `.glb` assets.
* **Attribute \& Index Extraction:** Implemented mesh and primitive iteration using `fastgltf::iterateAccessor<uint32\_t>` for index data and `fastgltf::iterateAccessorWithIndex<fastgltf::math::fvec3>` for `POSITION` and `NORMAL` vertex attributes.

### Renderer \& Shader Updates (`vlk.cpp`, `CommandPool.cpp`, `main.frag`)

* **Render Loop Integration:** Updated `vlk::init()` to load `assets/DamagedHelmet.glb` and bound the new `model.vb.buffer` and `model.ib.buffer` inside `CommandPool::recordCommandBuffer`.
* **Clay Material Pass:** Updated `main.frag` to output a solid clay shade (`vec4(0.65, 0.65, 0.65, 1.0)`) to validate geometry and silhouette rendering independently of textures and lighting.

## 3\. Bug Fixes \& Learnings

* **Vulkan-HPP Bitmask Flags (`E0304`):** Fixed `CommandBufferBeginInfo::setFlags` compilation error by wrapping `vk::CommandBufferUsageFlagBits::eOneTimeSubmit` inside `vk::CommandBufferUsageFlags{ ... }`.
* **Non-Copyable RAII Handles (`E1776`):** Fixed a copy-constructor error on `vk::raii::CommandBuffer` by passing it by reference (`vk::raii::CommandBuffer\&`) into buffer creation helpers.
* **Variable Shadowing \& Scope (`E0020`):** Moved `localVerts` outside inner attribute `if` blocks in `Mesh.cpp` so both `POSITION` and `NORMAL` passes populate the same vertex array cleanly.
* **Asset Relative Path Exception:** Resolved a runtime exception (`GltfDataBuffer::FromPath` failure) by correcting the path from `"DamagedHelmet.glb"` to `"assets/DamagedHelmet.glb"`.

## 4\. Known Issues (Pending)

* **Flat Clay Shading (No Depth/Contour Definition):** Because `main.frag` currently outputs a flat constant color (`0.65, 0.65, 0.65`), the helmet silhouette renders clearly but lacks surface normal shading to show 3D contours.
* **Multi-Primitive Draw Loop \& Node Transforms:** `CommandPool::recordCommandBuffer` needs to iterate over `model.primitives` using `prim.indexCount`, `prim.firstIndex`, `prim.vertexOffset`, and `prim.transform` rather than a single global draw call.
* **Shutdown Cleanup Order (`abort()` on exit):** Ensure `device.logicalDevice.waitIdle()` runs followed by `model.destroy(allocator)` strictly *before* `vmaDestroyAllocator(allocator)` during engine shutdown.

## 5\. Next Steps

* **Primitive Draw Loop \& Node Transforms:** Update `recordCommandBuffer` to loop through `model.primitives` and extract node transforms via `fastgltf::getTransformMatrix`.
* **Normal-Based / Directional Clay Shading:** Pass vertex normals from `main.vert` to `main.frag` and add basic directional/normal shading so the 3D surface details of the helmet stand out before moving on to PBR textures and descriptor indexing.
