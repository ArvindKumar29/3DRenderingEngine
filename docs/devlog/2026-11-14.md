# Engine Devlog — November 14, 2026

**Milestone 3 (Phase 2): Texture Pipeline — CPU Loading \& VMA Staging**

## 1\. Overview

Today's session focused on initiating the robust texture loading pipeline. Instead of a monolithic approach, the implementation is broken down to ensure safe memory handling between RAM and VRAM. We successfully completed CPU-side pixel extraction using `stb\_image` and established a Vulkan Memory Allocator (VMA) staging buffer for host-to-device transfers.

## 2\. Features Implemented

### CPU Pixel Extraction (`stb\_image.h`)

* Integrated `stb` via `vcpkg` and configured `CMakeLists.txt`.
* Isolated `#define STB\_IMAGE\_IMPLEMENTATION` into a dedicated `StbImage.cpp` file to prevent linker conflicts (multiple definition errors).
* Created the `Texture` class (`Texture.h`/`.cpp`) to manage image metadata (`width`, `height`, `channels`, `imageSize`) and pixel pointers.
* Forced RGBA channel layout during load via `STBI\_rgb\_alpha` to satisfy Vulkan's strict memory alignment requirements (bypassing 3-channel RGB alignment issues).

### VMA Staging Buffer Setup

* Configured a `VkBufferCreateInfo` with `VK\_BUFFER\_USAGE\_TRANSFER\_SRC\_BIT` to act as the source for future GPU memory copies.
* Allocated host-visible memory utilizing VMA flags: `VMA\_ALLOCATION\_CREATE\_HOST\_ACCESS\_SEQUENTIAL\_WRITE\_BIT | VMA\_ALLOCATION\_CREATE\_MAPPED\_BIT`.
* By leveraging `MAPPED\_BIT`, bypassed manual `vmaMapMemory`/`vmaUnmapMemory` calls for cleaner code.
* Executed `memcpy` to transfer raw pixel data into the mapped GPU staging buffer.
* Enforced strict memory hygiene by immediately calling `stbi\_image\_free(pixels)` after the transfer to prevent RAM leaks.

## 3\. Bug Fixes \& Learnings

* **Pointer Assignment Logic:** Fixed a critical logical error where texture metadata variables were incorrectly declared as pointers (`int\* width`) in the class header. Corrected this by using standard variables and passing their memory addresses (`\&width`) to `stbi\_load` for proper value assignment.
* **Standard Library Includes:** Resolved a minor compilation error for `std::runtime\_error` by explicitly including the `<stdexcept>` standard header in `Texture.cpp`.

## 4\. Next Steps

* Create the optimal device-local `VkImage` and `VkImageView` with `TRANSFER\_DST` and `SAMPLED` usage flags.
* Record a single-time command buffer to transition image layouts via Sync2 barriers (`UNDEFINED` -> `TRANSFER\_DST\_OPTIMAL` -> `SHADER\_READ\_ONLY\_OPTIMAL`).
* Execute `vkCmdCopyBufferToImage` to push data from the staging buffer to the final GPU texture.
